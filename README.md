# Multi-Criteria E-Commerce Recommendation System (TOPSIS & COMET)

This project implements an e-commerce product recommendation engine that integrates multi-criteria decision-making (MCDM) algorithms with personalized user context (Season, Geographical Location, and Holiday relevance).

## Project Structure
- `data/dataset.csv`: Dataset containing product features and personalization attributes.
- `src/`: Data loading, TOPSIS, and COMET recommendation models.
- `app.py`: Streamlit dashboard for interactive recommendation generation.

## Quick Start
```bash
pip install -r requirements.txt
streamlit run app.py
```
